# SENG4500 Assignment 1 – Server
Run the Server

Open a terminal in the server folder and run:

python server.py --port 4500

The --port argument specifies the TCP port that the server listens on.

The port is configurable. For example:

python server.py --port 5000

A valid TCP port must be between 1 and 65535.

Example output:

Server listening on port 4500

The server will continue running and wait for client connections.

To stop the server manually, press:

Ctrl + C
