# SENG4500 – Network and Distributed Computing

This repository contains my coursework and assignments for SENG4500 at the University of Newcastle.

The course covers concepts related to computer networks and distributed systems, including socket programming, TCP/UDP communication, network protocols, client-server architecture, and application-layer protocol design.

## Repository Structure

- `Assignment1/` – TCP-based client-server inventory system

Each assignment folder contains its own source code and README with specific instructions and documentation.
